= FreeHand parity
include::_attributes.adoc[]
:page-slug: parity

Every section of the {fh} manual ("Using FreeHand MX", Macromedia 2003, 412 pages), mapped to
the page of this book that delivers it, with the notable departures.  Each page carries the
full row-by-row table under its *FreeHand parity* section; this page is the index and the
audit trail.  Verdicts: *Faithful* (same behavior), *Adapted* (same intent, different
mechanism), *Dropped* (with reason), *Added* (no {fh} counterpart).

Unless a row says otherwise, everything in a section is Faithful.

== Chapter 1: FreeHand Basics (epic BASIC)

[cols="2,2,3"]
|===
|Manual section |Page |Notable departures

|The Studio MX interface; the Document window
|xref:workspace.adoc[The workspace]
|Panels dock inside the document window; one window with native tabs; the title bar shows sync state instead of an unsaved asterisk.

|Using panels
|xref:panels.adoc[Using panels]
|Answers panel → Help panel (bundled guide); Reset Layout command replaces deleting the prefs file.

|Using toolbars; the Tools panel
|xref:toolbars.adoc[Toolbars and the Tools panel]
|Save button → Save Version; Share button added; Xtra Tools built in; Action tool → Link tool.

|Setting the document view
|xref:document-view.adoc[Setting the document view]
|Anti-aliasing, Redraw While Scrolling and Better-but-slower display Dropped (always on); Flash Player window → Preview in Browser; right-mouse magnification Dropped.

|Using the right mouse button (Windows)
|xref:context-menus.adoc[Context menus]
|Brought to macOS: Control-click, secondary click, two-finger tap.

|Using preferences; tooltips
|xref:preferences.adoc[Preferences]
|Cmd+, with immediate apply; a *Sync and collaboration* category Added; Kodak CMS and PICT options Dropped; preferences sync with the account.

|Customizing; the quick-reference card
|xref:customizing.adoc[Customizing your environment]
|Shortcut sets sync with the account and export as `.wtkeys`; FreeHand 8, PageMaker and Director sets Dropped.

|Using and managing Xtras
|xref:extensions.adoc[Extensions]
|Renamed Extensions; all built in; third-party plug-ins out of scope for v1 (xref:decisions.adoc#D-019[D-019]).
|===
