# WireTuner 0.1.0 beta

## New in this build
- **Local mode**: the app now runs as a standalone app with no account or server. No "Sign in to sync", no warnings about unsynced changes when you quit, and no sign-in menus.
- **The Library works on its own**: it shows your documents as "On this Mac", and rename, duplicate, folders and a Trash (Restore, Delete Permanently, Empty Trash) all work.
- **File › Save a Copy As…** (⌥⇧⌘S) saves a `.wiretuner` file — the way to keep a copy or move work to another Mac. Double-clicking a `.wiretuner` file opens it as a new document.
- A smaller download (about 100 MB, from 141 MB).

## Using it without a server
There is no WireTuner server yet, and the app works on its own:
- Your documents are saved automatically on this Mac and listed in the Library window.
- Export (PDF, SVG, PNG and more) and printing work normally.
- Save Version and the History panel keep versions on this Mac.
- Sharing, comments, branches, restoring versions, publishing links and team libraries need a WireTuner account; they are shown but disabled with that reason.
- There are no automatic updates yet; new builds are published on the GitHub releases page.

## What to try
- Drawing and editing paths and shapes — a rectangle's, ellipse's or polygon's points are editable directly (the shape becomes a path in the same undo step).
- Text: fonts, sizes, alignment and leading from the Text menu and the Text toolbar's font picker.
- The panels: translucent glass panels that snap to the window edges and to each other; drag a title to move a group of panels, Option-drag to pull one away.
- Typeface documents: glyph drawing, OpenType features, UFO import and export.

Please report problems with what you did, what you expected, and what happened.
