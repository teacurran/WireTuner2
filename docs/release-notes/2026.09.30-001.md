# WireTuner 0.1.0 beta

## New in this build
- **Open Illustrator, PDF, SVG, EPS, DXF and FreeHand files as documents** with File › Open File… (⇧⌘O), the Library's Open File… button, dropping files on the Library, or double-clicking them in the Finder. Each file becomes a new document, with one page per PDF page or Illustrator artboard (named after the artboard). The original file is never changed.
- **Illustrator layers**: Illustrator files, and PDFs saved from Illustrator, open with their real layers: names, order, hidden and locked layers, and the artwork on hidden layers.
- **FreeHand import**: FreeHand 3 to MX files (`.fh*`) open or import with their pages, layers, clipping groups, symbols, named and spot colours, text and tiled fills. Blends and live effects come in expanded, with a note.
- **Publish as HTML**: Choose… now opens its folder panel, and Publish with no folder set asks for one. The folder stays writable after a restart. Cancel stops a publish without leaving a half-written folder, the sheet shows progress, and a pop-up picks the browser that opens the result. The same Choose… fix applies in HTML Setup, Document Setup and Data Merge.
- **Find & Replace** selects by colour, style, fill type and stroke type. It recolours gradient stops and tints, removes overprinting and contents, replaces path shapes from the clipboard, and resamples blends for the printer resolution.
- **Transform options**: turning Fills or Contents off in the Transform panel now takes effect. Gradients and tiled fills stay put, and a clip group's contents stay while its clipping path transforms.
- **Text**: drag a text style from the Styles panel onto text. Plain text files import with File › Import or by dropping them on the canvas. The Style Behavior sheet has a tab ruler.
- **Typeface documents**:
  - Drag the side-bearing lines on the glyph canvas.
  - Components and anchors show on the canvas and can be dragged.
  - Copy and paste glyphs, and use Paste as Component.
  - The Glyph menu works on the selected glyphs: set widths and bearings, centre, build accented glyphs, decompose and clean up outlines.
  - The Object panel has Glyph, Component and Anchor sections.
  - The glyph grid shows encoding placeholders.
- **Exports** keep an image's crop and colour treatments in PDF, SVG, EPS and DXF. Wide-gamut colours export consistently across pages.
- **The Calligraphic Pen** has an angle dial, and its strokes end flat.
- **A smaller download**: the app is 135 MB (was 213 MB) and the disk image about 66 MB (was 102 MB).

## Using it without a server
There is no WireTuner server yet, and the app works on its own:
- Your documents are saved automatically on this Mac and listed in the Library window.
- Export (PDF, SVG, PNG and more) and printing work normally.
- Save Version and the History panel keep versions on this Mac.
- Sharing, comments, branches, restoring versions, publishing links and team libraries need a WireTuner account; they are shown but disabled with that reason.
- There are no automatic updates yet; new builds are published on the GitHub releases page.

## What to try
- Open your own Illustrator, PDF, EPS and FreeHand files with File › Open File…
- Publish a document as HTML to a folder, then publish it again.
- Find & Replace by colour or style across a document.
- Typeface documents: drag bearings, components and anchors, and copy glyphs between fonts.

Please report problems with what you did, what you expected, and what happened.
