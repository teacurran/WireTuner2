A template is a document you start other documents from.  It carries everything a document can:
pages and their sizes, master pages, guides, layers, graphic and text styles, swatches, symbols,
brushes, custom page sizes and custom units, and any objects you leave on the pages.  Templates
live in your library like any other document, marked with a template badge, and appear in the
*New from Template* gallery.  One of them can be your default for menu:File[New].

== Starting a document from a template

To create a document from a template:

. Choose menu:File[New from Template…] (kbd:[Cmd+Shift+N]).  The gallery opens; it also appears
  when {product} launches with no document open, unless you turn that off in
  menu:{product}[Settings… > General] (*Show the gallery at launch*).
. Pick a template:
* *Starting points* -- built in: *Blank* (one Letter page), *Print* (a CMYK document with bleed and
  print marks presets), *Screen* (an RGB document in pixels with a web-safe swatch set), *Stationery*
  (letterhead, envelope and business card pages with guides), *Publication* (a multi-page document
  with facing pages, a master page and folio text), *Technical* (a pica-and-inches document with a
  fine grid and a technical stroke set).
* *My templates* and each team's templates from the library.
. For a starting point, set the size, orientation, units, color mode and, for *Publication*, the
  number of pages in the side panel.
. Click btn:[Create].

The new document is an untitled copy; the template itself is untouched.

== Saving a document as a template

Any document can become a template.

To make a template from the current document:

. Set the document up: pages, masters, guides, styles, swatches, defaults, and any objects every
  new document should start with.
. Choose menu:File[Save as Template…].
. Type a name, choose *My templates* or a team, and click btn:[Save].

A *copy* of the document is stored as the template; the document you were working in stays a
normal document.  To turn an existing document into a template in place, select it in the Library
window and choose *Use as Template* from its context menu; *Use as Document* reverses it.

To edit a template, open it from the Library window's *Templates* section: it opens as itself, not
as a copy, and edits are saved to the template.  Documents already made from it are not affected.

To delete a template, move it to the trash in the Library window.  Documents made from it keep
everything they inherited.

== The default template

menu:File[New] creates a document from the default template.

To change the default template:

. Choose menu:{product}[Settings… > Document] (kbd:[Cmd+,]).
. Under *New document template*, choose *Built-in* or a template from the list of your own and
  your teams' templates.
. Close the settings window.

The preference is yours and follows you to your other Macs.  If the template is later deleted or
unshared, menu:File[New] falls back to *Built-in* and tells you once.

== What a template carries

Everything in the document: guides, layers and their settings, graphic and text styles, swatches
including custom colors, symbols and master pages, all objects, custom brushes, custom page sizes,
custom units, document units, grid settings, printer resolution, and the default attributes for
new objects.  Not carried: the template's history, its collaborators and sharing, comments, and
your own view state.

== Working with others

A template stored in a team's library is available to every member; a change to it affects
documents created afterwards.  Two people can edit a template at the same time, as with any
document.  If someone deletes a template you had as your default, your next menu:File[New] uses
*Built-in* and says why.  Creating a document from a template while offline works if the template
is available offline on your Mac; team templates are cached the first time you use them.

== Specification

=== Data model

No document fields.  The template flag is document metadata on the server (`document.is_template`
in the `document` table, exposed through `DocumentService` as `is_template` on the document
resource and in `List` filters), because it describes how the library treats the document, not its
content.  Built-in starting points are textproto resources in `WTModel` parameterized by the side
panel's options.

The *New document template* preference is `Preferences.new_document_template` (a document id or
empty for built-in) in `AccountService`.  *Show the gallery at launch* is a local preference.

=== Merge semantics

Nothing in the document merges differently for templates.  Creating a document from a template
copies the template's current snapshot into a single creation change with fresh ids
(xref:creating-opening.adoc[Creating and opening documents]); a template edit concurrent with
someone creating from it lands in the template only.  The flag is a server field with
last-write-wins semantics at the API level.

=== Offline behavior

* New from a cached template works offline; uncached team templates are dimmed with a reason.
* Save as Template offline creates the template locally and flags it on reconnect.
* Toggling the flag on an existing document requires the server; the context menu item is
  disabled offline.

=== Server

`DocumentService`: `SetTemplate(document, is_template)` and an `is_template` filter on `List`;
templates are ordinary documents for every other RPC, so sharing, trash, history and branches
apply unchanged.  Deleting a template referenced by users' preferences requires no server work;
clients fall back on `NOT_FOUND`.

=== Client

* Gallery window (`WTApp`): `NSCollectionView` of starting points and library templates with
  thumbnails (from the library cache), a side panel (SwiftUI) of options per starting point, and
  btn:[Create].  Shown at launch under `applicationOpenUntitledFile` when the preference is on.
* `WTModel.StartingPoints` builds each built-in template's initial change from parameters:
  size, orientation, units, color mode (sets the default swatch set), page count with facing
  pages and a master with folio text for *Publication*.
* menu:File[Save as Template…] runs `DocumentService.Duplicate` then `SetTemplate` (or the local
  equivalents offline); the Library window's Templates section and context menu items are part of
  the library UI (APP-009) and this epic adds the flag handling.

NOTE: As built by DOC-029 (`WTModel/StartingPoints.swift`, `WTApp/Library/TemplateGallery.swift`,
`WTSync/TemplateDownload.swift`).  `StartingPoints.state(for:)` composes a starting point from the ordinary commands on a scratch
document (the built-in template, then `SetPageGeometry`, `SetUnits`, `AddPages`, `AddGuides`, `NewMasterPage`,

document id); menu:File[New] falls back to Built-in when the template is trashed or cannot be read and says so once per template
on this Mac.
