A halftone screen is how a printing press or imagesetter renders a tint: a pattern of dots (or
lines, or ellipses) whose size varies with the ink coverage, laid at an angle and a frequency.
The Print dialog sets the screen for each plate of the whole document
(xref:printing.adoc[Printing]).  The Halftones panel lets you give particular objects a screen
of their own -- a coarse line screen on a background tint for effect, a finer screen on a
detailed logo -- that overrides the document's screen wherever those objects print.

Screens only matter on output that is actually halftoned: separations going to a platesetter
or imagesetter, or any printer when *Screen in {product}* is on.  On a desktop printer with the
option off, the panel's settings have no visible effect, and on screen the object looks the
same either way.

== Applying a halftone screen to objects

To apply a screen to selected objects:

. Select one or more objects.
. Choose menu:Window[Halftones].
. From the *Screen* menu, choose a dot shape, or *Default* to use the document's shape from the
  Print dialog.
. Set *Angle* by typing a value in degrees or dragging the dial.
. Set *Frequency* by typing a value in lines per inch or dragging the slider.

Every change applies immediately to the selection.  With several objects selected, a value that
differs among them shows as *Mixed*; choosing a value writes it to all of them.

[cols="1,3"]
|===
|Control |Meaning

|*Screen*
|*Default* (inherit the document's shape), *Round*, *Ellipse*, *Line*, *Diamond*, *Square* or
*Cross*.

|*Angle*
|0°--360°.  For an object printed on several plates, this one angle is used on every plate it
appears on -- which is the reason to use object screens mostly on single-ink objects, or
deliberately for a moiré-free special effect.

|*Frequency*
|Lines per inch, 1--600.  Lower is coarser.
|===

To remove an object's screen, choose *Default* for *Screen* and click btn:[Use document
settings], which clears the angle and frequency as well.  The object then prints with the
document's screen for whichever plate it lands on.

Object screens are part of the object's attributes: they copy and paste with it, survive
grouping, are saved in graphic styles (xref:styles.adoc[Styles]), and can be searched for with
Find and Replace (xref:find-replace.adoc[Find and replace]).  A group's screen applies to every
member that has no screen of its own.

== Overriding object screens at print time

In the Print dialog, with *Separations* chosen, the *Halftone screen* group has an
*Ignore object screens* checkbox.  Select it to print every object with the plate's screen,
without touching the objects.  It is the fastest way to get a clean set of plates from a
document whose object screens were set for a different press.

== Overprint

Overprint -- letting an ink print on top of another instead of knocking it out -- is a property
of a fill or a stroke, not of the halftone, and is set in the Object panel on that fill or
stroke (xref:fill-attributes.adoc[Fill attributes], xref:stroke-attributes.adoc[Stroke
attributes]).  Separations honor it; menu:View[Overprint Preview] shows it on screen.

== Working with others

An object's screen is an attribute like its fill: change it and collaborators see the panel
update for that object; two people setting a screen on the same object at once end up with the
later one, as a whole -- never one person's angle with the other's frequency.  If you were
offline and your screen lost, the merge review lists *Halftone* among the object's changed
properties with both values.

== Specification

=== Data model

One field on `CommonProps`, added by xref:printing.adoc#PRINT-001[PRINT-001]:

[source,protobuf]
----
// Excerpt of doc/v1/common.proto
message CommonProps {
  // ...
  // Object-level halftone screen; unset = document default.  ATOMIC because shape, angle
  // and frequency describe one screen (see doc/v1/print.proto).
  Halftone halftone = 11 [(wt.crdt.field).merge = MERGE_ATOMIC];
}
----

`CommonProps` rather than the appearance stack because the screen applies to the object, not
to one fill; there is no fill-level screen.  And
`PrintSettings.ignore_object_halftones` (a bool, STRUCT sibling of the fields on
xref:printing.adoc[Printing]).

=== Merge semantics

* The panel writes `CommonProps.halftone` on each selected node in one change labelled
  `Change halftone of N objects`; btn:[Use document settings] writes it unset.
* ATOMIC LWW: concurrent angle and frequency edits on one object yield the later whole
  screen.  The review sheet lists a lost write as a `same register` property conflict named
  *Halftone*, with both screens shown as `Line 45° 40 lpi` strings.
* Edit vs delete follows the node rule: the screen is retained on the deleted node.
* Read-time: `frequency` outside 1..600 reads as inherit (0); `angle` is reduced modulo 360.
  A group's screen applies to members whose own field is unset (resolution walks up the
  parent chain at render time; nothing is written).

=== Offline behavior

Works offline.

=== Server

Nothing beyond storing and relaying changes.

=== Client

* `WTApp/Panels/HalftonesPanel`: SwiftUI panel body hosted by APP-004, registered in
  menu:Window[Halftones].  Bound to the selection through the APP-007 `PropertyEditor`
  protocol so the focus-preservation and `Mixed` rules apply.  The angle dial is a custom
  `NSControl` (drag around the centre; kbd:[Shift] snaps to 15°); the frequency slider is
  logarithmic from 1 to 600.
* Resolution for output: `WTRender`'s plate mode (PRINT-007) asks each object for its
  effective `Halftone` -- own, else nearest ancestor's, else the plate's -- and the in-app
  screener (PRINT-009) uses it per object.  With `ignore_object_halftones` the lookup stops at
  the plate.
* Undo: one change per panel commit; dial and slider drags group from mouse down to mouse up.

NOTE: As built by PRINT-009 (render half).  `HalftoneScreen` (`WTRender/Plates/Halftone.swift`)
reduces the angle modulo 360 and reads a frequency outside 1--600 as 60; inheritance (*Default*,
frequency 0) is resolved by WTModel before the screener sees a screen.

NOTE: As built by PRINT-009 (model half; `WTModel/Halftones.swift`).  `Halftones.objectScreens`
gives the screener each top-level object's own `CommonProps.halftone`, an unset shape taking the
plate's shape and a frequency of 0 (or outside 1--600) the plate's frequency; a screen with both
inherited is no object screen, and *Ignore object screens* gives none.  The screener assigns screens
per top-level item, so a group's screen covers its members and a member's own screen inside a group
is not separable; resolution through groups (PRINT-010) needs member-level spans in WTRender's
`ScreenAssignment`.

NOTE: As built by PRINT-010 (`WTApp/Print/HalftonesPanel.swift`; `WTModel/ObjectHalftones.swift`, a new file).
`SetObjectHalftone(nodes, halftone:)` writes `CommonProps.halftone` whole on each unlocked object ("Change halftone of N
objects"), nil unsetting it (btn:[Use document settings]); the panel changes one part of each object's own screen and
writes it whole, one change for the selection, and shows `Mixed` where the objects differ.  `ObjectHalftones.effective`
resolves an object's screen through its enclosing groups (own, else the nearest group's).  Deviations: the angle dial is
a slider stepping 15° (the custom `NSControl` is not built) beside the typed field, and the frequency slider is
logarithmic from 1 to 600 lpi as specified; the screener still reads top-level objects' own screens
(`Halftones.objectScreens`), so feeding it the group resolution needs member-level spans in `ScreenAssignment`.  The
*Ignore object screens* checkbox is in the print pane.  Merge tests: `OutputAreaTests` (WTModel).
