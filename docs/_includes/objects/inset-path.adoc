Inset Path makes copies of a closed path that follow its outline a set distance inside or
outside it -- one copy, or a series of them stepping inward like contour lines.  The copies
keep the original's attributes, so an inset with several steps and a gradient fill on each
gives a quick concentric effect.

To inset a selected closed path:

. Choose menu:Modify[Alter Path > Inset Path], or click *Inset Path* on the Path Operations
  toolbar.
. In the sheet, set:
+
[cols="1,3"]
|===
|Option |Meaning

|Steps
|How many paths to make.  `1` replaces the original with a single inset path; more makes
that many paths, grouped, stepping inward (or outward).

|Spacing (steps above 1)
|*Uniform* -- equal distance between successive paths.  *Farther* -- wider gaps near the
original, narrower ones toward the center.  *Nearer* -- narrower gaps near the original,
wider ones toward the center.

|Inset
|The distance from the original to the last path, in the document's unit, typed or dragged
on the slider.  Positive values go inside the original; negative values go outside.

|Join
|Miter, round or bevel corners on the new paths.

|Miter limit
|How far a mitered corner may extend before it is beveled.
|===
. Click btn:[OK].

Whether the original survives follows *Path operations consume original paths* and
kbd:[Shift], as for every path operation (xref:combining-paths.adoc[Combining paths]).  An
inset that would collapse a path to nothing -- a distance larger than the shape's narrowest
half-width -- produces no path for that step.

Open paths cannot be inset; expand their stroke first (xref:expand-stroke.adoc[Expanding a
stroke]).

== Working with others

Inset replaces the original with new paths (or a group of them).  See
xref:combining-paths.adoc[Combining paths] for what collaborators see and what happens to
edits made to the original at the same moment.

ifdef::spec[]
== Specification

=== Data model

No fields.  Steps = 1: one new path node replacing the original (per the consume rule).
Steps > 1: a `GroupProps{kind: GROUP}` node at the original's slot containing one path node
per step, outermost first (bottom of the stack).  Each path carries a copy of the original's
attribute stack under fresh element ids and identity `transform` with pasteboard-space
geometry.

=== Merge semantics

As for a combine with one input (xref:combining-paths.adoc[Combining paths]).  The
*Farther*/*Nearer* spacing is a geometric choice with no merge consequence.

=== Offline behavior

Fully offline.

=== Server

Nothing beyond storing and relaying changes.

=== Client

* `InsetPathCommand(steps:, spacing:, distance:, join:, miterLimit:, keepOriginal:)` over
  `WTGeometry.Offset.inset` (GEO-003).  Spacing: uniform gives distances
  `d·k/n`; *farther* gives `d·(k/n)^0.5`; *nearer* gives `d·(k/n)^2`, for `k = 1…n`.
* `Offset.inset` returns an empty path when the offset cannot be computed, never its input;
  `Offset.checkedInset` throws `OffsetError` instead.
* Degenerate steps (empty offset result) are skipped; if every step is empty the command
  does nothing and the sheet reports it.

NOTE: As built by OBJ-030 (`WTModel/PathOperationCommands.swift`, `InsetPathCommand`; the sheet
`WTApp/Objects/PathOperationSheets.swift`).  `InsetPathCommand(nodes, steps:, spacing:, distance:, join:, miterLimit:,
keepOriginal:)` takes unlocked closed paths, rectangles, ellipses and polygons.  Each input's filled region in pasteboard
space goes through `Offset.insetSteps` (the spacing curves are GEO-003's `InsetSpacing`); collapsed steps are skipped.  One
step makes one path at the input's slot; more make a group there with one path per step, outermost first -- for a negative
distance the last step is the outermost, so the order is reversed.  Each path carries a copy of the input's stack (`Even/odd
fill` off: results are normalized regions).  An input whose every step collapses is left alone and kept; the others are
deleted unless kept.  One change "Inset Path".  The sheet: *Steps* (1--100), *Spacing* (disabled for one step), *Inset* by
slider (±100) or a field in the document's unit, *Join*, *Miter limit*; the steps and inset are remembered on this Mac
(`tools.inset.steps`, `tools.inset.distance`).  When every step of every path would collapse the sheet says "The inset is
larger than the path: nothing would be left." and btn:[OK] is disabled.  The keep-original rule and title follow Expand
Stroke's.  Tests: `PathOperationCommandsTests`, `PathOperationSheetsTests`.
